# Firmalo SEO tracking

## Semantic core vs rank tracker

Firmalo follows the same policy as Go Latam:

- `semantic-core*.json` / full CSV = full demand map and SEO backlog.
- Rank tracker import = trimmed representative KPI set.
- Backlog keywords are not discarded. They stay available for copy guidance, FAQ/H2/H3, internal links, content briefs, and future page waves.

Current split:

- Policy/report: `tracking-vs-backlog-2026-06-30.md`
- Recommended tracker import: `rank-tracker-import-2026-06-30.csv`
- Backlog keyword queue: `semantic-core-backlog-2026-06-30.csv`
- Full expanded draft core: `semantic-core.expanded-2026-06-30.json`

## Return loop

After 1–2 weekly ranking/GSC snapshots, reopen `tracking-vs-backlog-2026-06-30.md` and `semantic-core-backlog-2026-06-30.csv` before adding new tracked keywords. Promote backlog keywords only when GSC/rank data, new page publication, or SERP review confirms a canonical target.

Do not overwrite historical dated imports. Create a new dated import file for each tracker update.
